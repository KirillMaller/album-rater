# data/

- `base-prompts.txt` — база вопросов, по одному на строку. Пишет человек.
- `base-answers.txt` — база ответов, по одному на строку.
- `state.json` — автосохранение игры, в `.gitignore`. Удалять можно, игра начнётся с нуля.

⚠️ **Сами карты в git не попадают.** `base-prompts.txt` и `base-answers.txt`
в `.gitignore`: тексты пишет человек, они про конкретных живых людей, а
репозиторий публичный. Формат и примеры — в `base-prompts.example.txt` и
`base-answers.example.txt`, вот они версионируются. Ставишь игру на новую
машину — скопируй примеры в рабочие файлы и пиши свои карты, либо залей их
через панель организатора: шестерёнка → «Загрузить карты».

Пустые строки и строки, начинающиеся с `#`, пропускаются.
Файлы читаются в момент «Начать игру» — базу можно править без перезапуска сервера.
