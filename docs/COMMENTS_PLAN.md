# Комментарии к баттлам, вход и оценки по трекам

## Объём

- Под баттлом отдельный раздел «Комментарии». Сверху страницы ссылка «Обсудить». Гостю видны сообщения и вход, зрителю после принятия условий видны поле комментария и публичный ник. Автор может убрать своё сообщение, администратор может скрыть любое.
- Один выбор входа для шапки, голосования и комментариев. Twitch использует штатный провайдер Supabase. Для YouTube подходит тот же Google-аккаунт. Из существующего профиля можно привязать Twitch и сохранить прежние голоса.
- В треклисте «Рифмобес», «Моя» и «Зрители». У средней зрителей виден счётчик по треку. Прочерк означает отсутствие оценки. Список голосов на странице записи загружается порциями.
- Два фона переведены в WebP с прежним разрешением. Макет главной остаётся в текущем варианте.

## Перед публикацией

1. Применить миграцию `db/migrations/020_battle_comments.sql` сначала на тестовой базе. Проверить гостя, автора, другого пользователя, администратора, неопубликованный баттл, ограничение частоты, скрытие, выдачу порциями и отсутствие служебных полей в публичном ответе. Существующие голоса остаются доступны с прежней версией условий. Публикация требует версию 2.
2. Зарегистрировать приложение Twitch для нужного окружения. Указать callback Supabase в Twitch Developer Console. Включить Twitch и ручную привязку в Supabase Auth, настроить разрешённые адреса возврата. Client Secret хранить только в настройках провайдера. [Twitch в Supabase](https://supabase.com/docs/guides/auth/social-sign-in/auth-twitch), [привязка способов входа](https://supabase.com/docs/guides/auth/auth-identity-linking)
3. На тестовой версии проверить вход обоими способами, возврат к исходному баттлу, отмену входа и привязку Twitch к старому профилю с голосами. Проверить обычный и административный аккаунты, публикацию и скрытие комментария с телефона, счётчики после сохранения и обновления страницы.
4. Указать дату фактического запуска в политике, условиях и объявлении на главной. Владелец выбрал объявление на сайте для этой редакции. Предыдущая редакция предусматривала уведомление по почте за 14 дней. Новая редакция описывает объявление на сайте.
5. Миграция 020 применена к рабочей базе. Запись до релиза закрыта. После публикации сборки и проверки документов вернуть право через `grant execute on function public.post_battle_comment(uuid, text, text) to authenticated;`. При откате отозвать это право и вернуть предыдущую сборку, сохранив уже опубликованные комментарии.

## Порядок включения Twitch

Комментарии запускаются с действующим Google-входом. После подключения Twitch и ручной привязки в Supabase установить переменную репозитория `VITE_TWITCH_ENABLED=true` и запустить workflow Deploy из `main`. Переменная управляет видимостью кнопок входа и привязки.

## Граница первого выпуска

Обсуждение относится ко всему баттлу. Имена YouTube-каналов, дополнительные вопросы, ответы на комментарии и зрительские предложки отложены. Реализация использует текущие React, Vite и Supabase.
